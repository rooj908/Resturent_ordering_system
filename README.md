# 🍽️ Restaurant Ordering System

A modern and interactive Restaurant Ordering System designed to provide a smooth and convenient online food ordering experience. Customers can explore the menu, select their favorite dishes, manage their cart, and place orders through a user-friendly interface.

## 🚀 Live Project

- **Google AI Studio:** [View Project](https://ai.studio/apps/915d1be5-1459-46b4-9957-46aa4c4ae25e)
- **GitHub Repository:** [Restaurant Ordering System](https://github.com/rooj908/Resturent_ordering_system)

## ✨ Features

- Modern and responsive user interface
- Interactive food menu
- Food categories and item selection
- Add to cart and remove items
- Quantity management
- Order summary and total calculation
- Customer-friendly ordering experience
- Dynamic UI interactions

## 📂 Project Setup

Follow these steps to run the project locally.

### Prerequisites

- Node.js installed
- npm package manager
- Gemini API Key

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/rooj908/Resturent_ordering_system.git
```

**2. Navigate to the project folder**

```bash
cd Resturent_ordering_system
```

**3. Install dependencies**

```bash
npm install
```

**4. Configure environment variables**

Create or update the `.env.local` file in the root directory:

```env
GEMINI_API_KEY=your_gemini_api_key
```

Replace `your_gemini_api_key` with your actual Gemini API key.

**5. Start the development server**

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the application.

## 🔐 Environment Variables

For security reasons, never upload your actual API key or `.env.local` file to GitHub.

Make sure `.env.local` is included in `.gitignore`.
